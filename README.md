# GG Lounge: Real-World Game Center Web Application

## Overview
Developed a comprehensive web application for **GG Lounge**, a real-world game center, aimed at enhancing user experience and management efficiency. The platform enables users to:

- Browse available games and their schedules.
- Place bookings and make secure payments.
- View customer feedback on games and services.
- Stay informed about upcoming events.
- Create and manage user accounts.

## Key Responsibilities
- Led a team of six members to design and implement the bookings feature, enabling users to view current reservations and place new bookings for selected games on their desired dates.
- Allow admins to download a summary in PDF format.
- Oversaw the development process, ensuring quality and timely delivery of project milestones.
- Collaborated with team members to integrate features like user account management and payment processing.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript 
- **Backend:** PHP
- **Database:** MySQL

## Skills Gained
- Team leadership and project management
- Web application development
- User experience design
